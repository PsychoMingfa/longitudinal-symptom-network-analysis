## What the code does

- `data_analysis_dep.R`: depression network temperature analysis.
- `data_analysis_anx.R`: anxiety network temperature analysis.
- `fixed_cohort_replication.R`: fixed-cohort replication analysis.
- `primary_sleep_three_group_temperature_analysis.R`: primary sleep-group temperature analysis.
- `exploratory_sleep_five_phenotypes_temperature_FDR.R`: exploratory five-phenotype sleep analysis with FDR correction.
- `symptom_burden_LMM.R`: longitudinal mixed-model analysis of symptom burden.

## Data note

Raw participant-level data are not included in this repository because the study uses human-participant mental-health data. Data access should follow the approved institutional or project data-sharing procedure.
